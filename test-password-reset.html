Résumé du Flux Complet

  1. Utilisateur demande reset → Email envoyé avec ${APP_URL}/index.html#access_token=xxx&type=recovery
  2. Clic sur lien → auth.js:checkRecoveryMode() détecte le hash
  3. Appel showAuthModal('reset') → Affiche auth-form-reset
  4. Utilisateur entre nouveau mot de passe → handleAuthReset()
  5. Extraction du token du hash → Auth.updatePassword()
  6. Backend met à jour via Supabase → Succès
